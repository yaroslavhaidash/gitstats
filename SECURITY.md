# Security

Please report vulnerabilities privately, not in a public issue: use **GitHub's private vulnerability reporting** on this repo (Security tab → "Report a vulnerability"). Include what you found, how to reproduce it, and what it lets someone do.

This is a side project run by one person, so replies may take a few days. You'll get an acknowledgement, and credit in the fix if you want it.

In scope: the gitstats.org app in this repo, and the CLI at github.com/yaroslavhaidash/gitstats-cli (report CLI issues there). Please don't test against other members' accounts or data, and don't run load tests against gitstats.org.

How the privacy model works, and the review that shaped the CLI path: `docs/PRIVATE-ACTIVITY.md`, `docs/SECURITY-REVIEW-CLI.md`.
